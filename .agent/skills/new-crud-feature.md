# Skill: Criação de Novo Recurso / CRUD

Instruções e fluxo de trabalho para implementar uma nova funcionalidade ou entidade no projeto `minha-sala-server`.

---

## Fluxo Sequencial de Execução

Ao receber uma demanda para criar um novo recurso (ex: `Equipamento`, `Reserva`, `Bloco`):

1. **Migration Flyway**:
   - Verifique os arquivos em `src/main/resources/db/migration/` e defina a próxima versão `V{n}__{descricao}.sql`.
   - Crie a tabela com comandos ANSI SQL (`BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`, constraints, etc.).
2. **Entidade JPA (`model/`)**:
   - Crie a classe em `br.senai.minha_sala.model`.
   - Adicione anotações `@Entity`, `@Table(name = "...")`, `@Id`, `@GeneratedValue(strategy = GenerationType.IDENTITY)`.
   - Configure atributos e construtores/getters/setters.
3. **DTOs (`dto/`)**:
   - Crie `{Recurso}Request.java` como `record` com anotações de validação (`@NotBlank`, `@NotNull`, etc.).
   - Crie `{Recurso}Response.java` como `record` contendo os dados expostos e o `id`.
4. **Repository (`repository/`)**:
   - Crie a interface `{Recurso}Repository.java` estendendo `JpaRepository<{Recurso}, Long>`.
5. **Service (`service/`)**:
   - Crie `{Recurso}Service.java` anotado com `@Service` e `@Transactional(readOnly = true)`.
   - Implemente: `listar()`, `buscarPorId(Long id)`, `criar({Recurso}Request dados)`, `atualizar(Long id, {Recurso}Request dados)` e `excluir(Long id)`.
   - Implemente o método privado `toResponse({Recurso} entidade)`.
6. **Controller (`controller/`)**:
   - Crie `{Recurso}Controller.java` anotado com `@RestController` e `@RequestMapping("/recursos")`.
   - Implemente os 5 endpoints REST com os códigos HTTP corretos (`200`, `201` + cabeçalho `Location`, `204`, etc.).
7. **Verificação de Compilação**:
   - Compile o projeto (`./mvnw.cmd compile`) para certificar que tudo compila perfeitamente.
   - **Atenção**: NÃO crie classes nem métodos de teste em `src/test/java`.
