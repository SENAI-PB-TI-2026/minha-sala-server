# Skill: Migração de Banco de Dados (Flyway)

Procedimento seguro para criar e aplicar alterações no banco de dados do `minha-sala-server`.

---

## Passo a Passo

1. **Checagem de Sequencial**:
   - Liste os arquivos existentes em `src/main/resources/db/migration/`.
   - Identifique o maior número de versão atual (ex: se existem `V1` e `V2`, o próximo será `V3`).
2. **Definição do Nome do Arquivo**:
   - Formato: `V{n}__{descricao_em_snake_case}.sql`
   - Exemplos:
     - `V3__create_reservas_table.sql`
     - `V4__add_bloco_to_salas.sql`
3. **Escrita do Script SQL**:
   - Use comandos DDL padrão ANSI:
     ```sql
     -- Criar nova tabela
     CREATE TABLE equipamentos (
         id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
         nome VARCHAR(100) NOT NULL,
         numero_serie VARCHAR(100),
         sala_id BIGINT,
         CONSTRAINT fk_equipamentos_sala FOREIGN KEY (sala_id) REFERENCES salas(id)
     );

     -- Alterar tabela existente
     ALTER TABLE salas ADD COLUMN bloco VARCHAR(50);
     ```
4. **Sincronização com o Código Java**:
   - Atualize a entidade correspondente em `br.senai.minha_sala.model`.
   - Atualize os records DTOs (`*Request` e `*Response`) conforme aplicável.
5. **Validação**:
   - Execute `./mvnw.cmd compile` para validar consistência.
